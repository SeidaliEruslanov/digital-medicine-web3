# Цифровая медицина и Web3

Интерактивный учебный лонгрид об электронной коммерции и криптовалютах в цифровой медицине.

## Что есть в проекте

- Восемь разделов и кликабельное оглавление с якорями.
- Путь медицинского заказа: четыре этапа, роли участников и сценарии ошибок.
- Сравнение денежных инструментов и учебная модель изменения курса.
- Матрица доступа к данным и вопрос с объяснением ответа.
- Тринадцать внешних источников с фильтром, включая исследования, стандарты и кейсы.
- Фотография, исходные иллюстрации FHIRChain и Exonum, авторские SVG-схемы.
- Локальное видео MP4 с русскими субтитрами VTT, текстовое пояснение и локальная звуковая иллюстрация WAV.

Все стили, скрипты и медиафайлы размещены в этом репозитории. Внешние шрифты, CDN и видеоплееры не требуются. Видео и звук запускаются вручную. JavaScript работает без библиотек и сборки. Адаптивная версия, клавиатурное управление вкладками и режим уменьшенного движения поддерживаются.

## Публикация

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

Для локального просмотра откройте index.html или запустите любой статический HTTP-сервер в папке проекта.
